# Project Structure

## Folders

- `scripts/`: analysis scripts
- `data/raw/`: original source CSV files
- `data/processed/`: cleaned and model-ready datasets
- `outputs/figures/`: charts and visual outputs
- `outputs/tables/`: regression tables and numeric results
- `outputs/reports/`: text summaries and diagnostics

## Main Entry

- `scripts/c2c_seller_performance_analysis.py`: main analysis pipeline
- `run_analysis.py`: simple project entry for running the analysis

## Run

```powershell
py .\run_analysis.py
```
